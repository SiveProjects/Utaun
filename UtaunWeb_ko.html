生成モード

Malchaモードは下のレコリスト1行 = 1wav。oto.iniはリストのエイリアス全部に合わせる。1wavに複数エイリアスが入るのがCVVC（連続音）。
フルモードは元ファイルと同じ、初声19 × 中声21 × 終声28 の全組み合わせ。

Malcha レコリスト（177行）

このまま使う。自分のリストに書き換えてもOK。

例：_ka'ka'_'kya'kya'_'kwa'kwa → 1wavに 카・캬・콰。otoは _ka / ka / _카 / 카 全部。

試聴 - 요 ≠ 유

元ファイルの作り方をそのまま使ってる。요 = ㅣグライド30ms + 오、유 = ㅣグライド + 우。だから 요 が ゆ に聞こえない。

音が出ない場合は iPhoneの消音モードをオフにしてください

oto.ini の合わせ方

元ファイルは wav = エイリアス1個 だった。Malcha版は 1wav = エイリアス複数 にした。

line001.wav=_ka,0,30,0,30,15
line001.wav=_카,0,30,0,30,15
line001.wav=ka,0,30,0,30,15
line001.wav=카,0,30,0,30,15
ローマ字でもハングルでも打てる。UTAUで _카 と 카 は同じwavの違う位置を指す。

変換：ka→카 ㅋ+ㅏ、ga→가 ㄱ+ㅏ、kka→까 ㄲ+ㅏ、in→인 ㅣ+ㄴ、um→움 ㅜ+ㅁ、ong→옹 ㅗ+ㅇ、il→일 ㅣ+ㄹ。R=休止、br=ブレス、ng=鼻音。

子音.wav が ひらがな名のとき

この版は consonants/か.wav みたいな ひらがな名でも見つかるようにした。

探す順番：ka.wav → ㄱ.wav → か.wav → カ.wav / list.json に か.wav が入ってればそれも拾う。

対応表：
ㄱ→が.wav / ㄲ→か.wav / ㅋ→か.wav
ㄴ→な.wav / ㄷ→だ.wav / ㄸ→た.wav / ㅌ→た.wav
ㄹ→ら.wav / ㅁ→ま.wav / ㅂ→ば.wav / ㅃ→ぱ.wav / ㅍ→ぱ.wav
ㅅ→さ.wav / ㅆ→ざ.wav / ㅈ→じ.wav / ㅉ→じ.wav / ㅊ→ち.wav
ㅎ→は.wav / ㅇ→ん.wav

※ ㄱ と ㅋ は両方 か.wav を使うと区別がつかない。分けたいなら ㄱ を が.wav、ㅋ を か.wav にしておくのがおすすめ。ㄸ と ㅌ、ㅃ と ㅍ も同じ考え方。
