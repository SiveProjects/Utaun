oto.ini の合わせ方

1wav = 1音。エイリアスは4種出す。

가.wav=ga,0,100,0,30,15
가.wav=가,0,100,0,30,15
가.wav=_ga,0,100,0,30,15
가.wav=_가,0,100,0,30,15
ローマ字でもハングルでも打てる。

変換：ka→카 ㅋ+ㅏ、ga→가 ㄱ+ㅏ、kka→까 ㄲ+ㅏ、in→인 はCVリストに無いので、VCが要る場合は別途。R=休止、br=ブレス、ng=鼻音。

子音.wav が ひらがな名のとき

consonants/か.wav みたいな ひらがな名でも見つかる。

探す順番：ka.wav → ㅋ.wav → か.wav → カ.wav / list.json に か.wav が入ってればそれも拾う。

対応表：
ㄱ→が.wav / ㄲ→か.wav (kka.wav があれば優先) / ㅋ→か.wav
ㄴ→な.wav / ㄷ→だ.wav / ㄸ→た.wav / ㅌ→た.wav
ㄹ→ら.wav / ㅁ→ま.wav / ㅂ→ば.wav / ㅃ→ぱ.wav / ㅍ→ぱ.wav
ㅅ→さ.wav / ㅆ→ざ.wav / ㅈ→じ.wav / ㅉ→じ.wav (jja.wav があれば優先) / ㅊ→ち.wav
ㅎ→は.wav / ㅇ→ん.wav

※ ひらがなだけだと ㄲとㅋ、ㄸとㅌ、ㅃとㅍ、ㅈとㅉ は区別がつかない。分けたいならローマ字名 (kka.wav / ka.wav、tta.wav / ta.wav、ppa.wav / pa.wav、jja.wav / ji.wav) で用意するのがおすすめ。
